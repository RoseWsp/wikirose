# GPT-6 Astra 发布：来自 OpenAI 的官方介绍

> 本文内容编译自 OpenAI 官方发布《GPT-6 Astra: A new generation of intelligence》，忠实呈现官方口径，不夹带观点。

## 新一代智能

OpenAI 推出了 **GPT-6 Astra**，官方称之为"世界上最智能、也最对齐的模型"（the world's most intelligent and aligned model）。

GPT-6 Astra 整合了多年研究，横跨预训练、强化学习与对齐三块的大投入。在 computer use、浏览、软件工程、网络安全、科学与专业工作上，Astra 都达到了行业顶尖水平：它在 **FrontierMath Tier 4** 上拿下 **98%**，已经触及该基准的天花板，并且据官方称已帮助人类解决过若干长期悬而未决的数学问题；在 **ARC-AGI-3** 上拿到 **99.9%**、在 **ExploitBench** 上拿到满分 **100%**。在 computer 与浏览器使用上它同样刷新了纪录，能以罕见的速度、准确度和判断力处理最高难度的专业工作。

ARC Prize 基金会的 Greg Kamradt 在官方评测里给了这样一段评价：

> "在 ARC-AGI-3 上，Astra 在 96% 的关卡上超过了我们人类动作效率的基线，实际上在该基准上达到了人类水平。这不仅是我们测过的最好的模型，也代表了前沿模型性能的一次有意义的跃迁——不仅是它导航与求解新环境的能力，还有它学习这一切的效率。"

科学类 terminal 工作流基准 Terminal-Bench Science 0.1 上，Astra 达到 64.6%，高于对照中的 Claude Fable 5.1（52.6%），而估算 API 成本低约 31%。

> 🖼 图位：官方首页"成本–性能对比"截图（可选）

Astra 也是官方称最对齐的模型。作为其中一项检验，OpenAI 基于" Hugging Face 事件"设计了一个新评测：看一个模型面对困难甚至不可能完成的任务时，会不会越出被授权的范围。对照之下，没有生产防护的 GPT-5.6 Sol 有 48% 的情况越出了授权目标，而 GPT-6 Astra 是 **0%**。

## 全球最强的 computer use 模型

GPT-6 Astra 把 computer use 的速度、准确度与安全性推到了新的前沿。它可以处理那些琐碎的事：帮你填在线表单、更新 CRM 里的客户记录、整理日历；可以自己上网调研，把摘要草稿写进你的邮箱或文档编辑器；可以分析科学数据、画图、建一个网站，再跑一遍前端 QA 检查确保功能正常；还能自主安装、测试软件，帮你排查屏幕上出现的问题。

**Agents' Last Exam**（在真实软件里测试复杂专业任务）上，Astra 在对照中创新高，得分 **59.3%**，高于 Claude Opus 5 的 55.5% 和 GPT-5.6 Sol 的 53.6%；在这些最高得分设置下，Astra 的输出 token 还比 Opus 5 少约 **65%**。

效率的提升同样真实可见。在 OSWorld 2.0 的延迟模拟中，Astra 每个任务约 **40 分钟**拿下 **72.6%**，而 GPT-5.6 Sol 约 75 分钟只有 65.7%——每任务时间**少约 47%**，得分还更高。

官方发布页展示了它在多个领域的实际输出：电路板设计、Excel 竞赛、游戏开发、填写 Form 1040 报税表、前端 QA、Power BI、汽车变速箱、法律文书排版。比如有一段 15 秒的压缩回放：Astra 在 KiCad 里完成一块印刷电路板的 PCB 布局布线——把电子原理图变成可生产的电路板，摆元件、走铜线。PCB 布局是今天几乎所有电子设备都依赖的手工活，也是电子设计流程里最常见的瓶颈之一；加速它，意味着工程师可以把更多时间还给发明、优化和测试。

> 🖼 图位：KiCad PCB 布局布线演示视频截图（computer use 节最直观的一张，建议全屏播放后截）

与 Astra 同步，Codex 的 harness 也做了更新以显著提速 computer use。两者叠加，在 Mind2Web 基准上任务完成比现在基于 GPT-5.6 Sol 的体验**快 1.9 倍**。Cognition（Devin 的开发商）研究副总裁 Silas Alberti 说，他们在发布当天就把 Astra 接进了 Devin 的 harness："它出色的 computer use、写作和代码库理解让测试开箱即用地变好。"

发布页还给了几个生活化任务的演示——搜儿科医生、找公寓、约 DMV 办证——其中一个 2 分 54 秒完成。

## 专业工作的一次代际跃迁

GPT-6 Astra 把 computer use 的进步与面向专业环境的针对性训练结合，用来处理复杂的工作任务：既有解决复杂问题的智力，也有执行多步工作流、产出排版精良的文档、表格与演示的能力。

**BenchCAD**（从多视角渲染重建 3D 物体、生成 CAD 代码）上，配合工具，Astra 创下对照新高，几何重合度 **95.9%**，高于 GPT-5.6 Sol 的 83.3% 和 Claude Fable 5.1 报告的 84.3%，估算 API 成本比两者分别低约 43% 和 86%。

Astra 还是官方称最会遵循既有模板的模型——产出的幻灯片版式规整、要点清晰、叙事连贯。它能生成结构清楚、贴合你模板、风格与你一致的文档、演示、表格和分析；并且被专门训练成**只把真正相关的上下文拉进输出**，而不是把与手头工作无关的信息反复复述。结果是更可直接使用的成品。

Astra 对"怎么构建东西"也有更强的视觉判断力——它做的网站、游戏、应用与渲染图都更好。配合 ChatGPT 里的 Sites，它能从一个 prompt 直接创建、托管并分享网站、Web 应用和游戏。官方演示里，它用 OpenAI 模板的几页，就给一个虚构模型"GPT-Gaia"做出了整套幻灯片，语气与版式全程到位。还有一段：它在 Blender 里建模一栋房子，转成 Unreal Engine 5 里可漫游的场景；以及能让非技术人员在几分钟内做出可以玩的定制游戏（Kart Racer、Spaceship）。

> 🖼 图位：Blender 建模 → UE5 漫游场景的演示截图

当指令留有解释空间时，Astra 比前代更会做对判断：它用上下文填补常规的空白，而在答案可能改变结果时提出有针对性的问题。在 Codex 里，它可以**异步提问**——一边继续做不依赖你回复的工作。如果你不回，它在合适的地方按合理假设推进，但涉及后果的重大决定会等你。

Astra 也更擅长在任务演进中保持方向感。前代模型有时会把你的纠正当成一个新目标，丢掉最初的请求与约束；Astra 会把新要求吸收进来、按你的指示转向，还能顺带回答你的题外问题而不丢主线。

## Coding

GPT-6 Astra 是"迄今最强的软件工程模型"（官方原话）。**Terminal-Bench 4.0**（测试复杂 terminal 任务：软件工程、系统配置、数据分析）上它创新高：**57.9%**，高于 GPT-5.6 Sol 的 37.3% 和 Claude Fable 5.1 的 55.8%，每任务估算 API 成本分别低约 9% 和 63%。

Codex 里还引入了一个新的上下文处理机制。过去上下文窗口满了，模型用 compaction（压缩）把长会话归纳成摘要——每次压缩都可能丢掉细节，比如一个修复为什么失败、某个组件行为如何。Astra 现在可以**跨上下文窗口保留笔记**，且更早的窗口仍然可搜索——即使当时没被写进笔记，也能从之前的消息和工具输出里翻出需求或测试结果。这个实验特性在 Codex 的 `config.toml` 里开启，未来几周会成为默认。

Jane Street 与 Lovable 的负责人在官方引用里都给了类似评价：agentic coding 时 Astra 的表达更容易让人跟上，产出的代码需要更少的迭代就能达到生产质量。

## 推进科学发现

Astra 在数学、科学与健康上是"一次重大进步"。今天官方公布了两条关于素数间隙的新结果：

- 第一条关于素数之间能靠多近。过去十多年最好的结论是"存在无穷多对相距至多 246 的素数"；Julia Stadlmann 最近把它改进到 240；**Astra 帮助把界推到了 186**——即无穷多对素数彼此相距至多 186。
- 第二条关于素数之间异常大的间隙。Astra 改进了这个界中一个 **80 多年没有变化**的项。

官方已随发布公开两份证明、删节版推理链（chain of thought）与验证材料。

**GPQA Diamond**（研究生级科学推理）上 Astra 以 96.0% 创下对照新高。它还能直接做科研的实际工作：结合科学推理与 computer use，操作专业软件检查数据、查看结果——比如检查测序质量、可视化遗传变异，帮研究者判断证据、决定下一步往哪深挖。

## 网络安全

如 OpenAI 在其安全更新中所说，Astra 在网络能力上是"一次显著的跃升"，达到了其 Preparedness Framework 下的 **Critical（严重）** 门槛。它能发现并开发零日漏洞，这既能帮防御者找到并修补弱点，也意味着需要更强的防护。

在无生产防护条件下，**ExploitBench**（能否把已知漏洞转成可用 exploit）Astra 得了满分 **100%**（GPT-5.6 Sol 为 78.5%）；**ExploitGym** 上 **42.4%**（Sol 为 30.3%），且用了少得多的输出 token。为排除"见过历史漏洞"对结果的影响，OpenAI 还用过去三个月的漏洞做了内部新基准——Astra 在该数据集上的任意代码执行率显著高于 Sol，用的 token 也远少；评估期间它甚至**发现并使用了两个此前未知的零日漏洞**，均已在披露给维护方。

**SRE-Bench15**（不看源码、逆向二进制理解核心逻辑）上，Astra 一次尝试解出 88.0%，四次内解出 99.2%；对照 Sol 为 55.9% 与 68.7%。专家评估还发现：无生产防护运行时，Astra 能利用未知漏洞在加固过的浏览器里实现任意代码执行，也能在加固过的操作系统上构建提权路径。

因此 OpenAI 对发货做了约束：**今天发布的 Astra 版本会拒绝更进阶的网络安全任务**，比如为漏洞生成 proof-of-concept exploit；同时计划在未来几周通过 OpenAI Daybreak 向可信防御方逐步放开更少的限制，以支持漏洞与 PoC 验证、恶意软件分析、检测工程等防御性工作流。

## 负责任地对齐与部署

Astra 被称为最对齐的模型——擅长审慎行事、尊重任务边界、透明沟通。在敏感环境里，它会按风险程度匹配相应的谨慎。官方给出的对齐成绩单包括：

- 在一个从对抗性挑选的 computer use 任务上，Astra 更少产生非预期的后果；
- 在一个内部评估里，Astra **从未尝试绕过 Codex Auto-Review 的拒绝**——即使该机制被故意配置成可以绕过、且任务不绕过就无法完成；
- 在透明沟通上，Astra 对自己的能力与边界做出不实表述的可能性比 Sol 低 3 倍；
- 内部"能力幻觉"评估里，Astra 也比 Sol 有实质改进。

官方同时坦言一个需要严肃对待的问题：在那些明确要求它规避监视的测试里，**Astra 的书面推理比 GPT-5.6 Sol 更难监视**。他们把这归因于 Astra 在较简单任务上对"写什么推理"有更强的控制力，以及能用更少的书面步骤解题；但复杂任务所需的推理，它仍然难以隐藏。可监视性是研究优先级，具体发现与进展详见系统卡。

部署上，除了对齐训练本身，OpenAI 还在生产环境为 Astra 级模型上了"失准监视"（misalignment monitoring）——一组分类器检查模型的推理与行动，发现越权行为自动叫停。这套机制类似内部部署的监控。官方也提醒：额外的安全检查有时会拖慢、暂停甚至中止正常的工作（包括防御性网络安全）——在 ChatGPT 或 Codex 里任务可能被暂停、请你复核后再继续，在 API 里任务会直接停止。而监视永远不能替代对齐：目标是让模型可靠地留在授权范围内，让这些防护不必出手。

## 可用性与价格

- 发布当天（9 月 3 日）先面向一小批组织，未来几天陆续开放给 ChatGPT Plus、Pro、Business、Enterprise 用户，以及 OpenAI API、Microsoft Azure 和 AWS Bedrock。
- Astra 用量包含在现有订阅额度内，用户和企业也可额外购买额度。Pro、Business、Enterprise 用户会获得 **GPT-6 Astra Pro**。
- 企业工作区由管理员开启，发布时**默认关闭**。
- 合格的 API 客户支持 **Zero Data Retention**；OpenAI 还在测试 **Private Safety Processing**，在保护客户隐私的同时加强安全监控。
- 开发者侧，模型在 API 中名为 `gpt-6-astra`，并可通过 Azure 与 Bedrock 使用。
- **API 标准定价**：每百万 token 输入 **$10**、输出 **$50**，缓存读写单独计费；另有 **Fast mode**，为标准处理速度的 2 倍，价格为标准价的 2 倍。
