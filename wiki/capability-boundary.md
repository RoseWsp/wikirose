# 模型能力边界

## TL;DR

AI 产品的三条边界：能力线会动、成本线会动，价值线锚在人性上不动。机会不在"想到一个好需求"，而在**模型能力边界刚好扫过的地方**——想法太早，烧的只是 Token。

## 在边界线上找需求

同一个需求，模型能力没到时是普通提示词，能力到了就能让所有人参与。Nano Banana：GPT 刚出画图时要手动输入城市、天气一大堆信息，有人围观，不火；Gemini 内置搜索能自己查天气后，提示词简化到"输一个城市名"，从中文圈火到 Google CEO 致谢。**需求一直都在，是能力边界刚好扫过了它**。所以找需求要盯着模型进化方向：GPT-3 自动补全→ChatGPT 对话→Agent 调工具，每次升级边界外扩一圈，扫过的地方全是新需求。([[baoyu-ai-native-thinking]])

## 想法不是关键，时机才是

AutoGPT（2023）和 Manus 是同一个"通用 Agent"的想法：AutoGPT 火了一阵就凉——那时 Agent 能力没到，任务打转，烧大把 Token 交付不了结果；Manus 出现在能力刚好够到的时刻，一夜刷屏。结论：**想法不是关键，能力边界才是。想法太早，烧的只是 Token。**

## 三条边界

| 边界 | 会不会动 | 判断标准 |
|------|---------|---------|
| 能力 | 会动 | AI 现在做不做得到？ |
| 成本 | 会动 | 账单撑不撑得住？ |
| 价值 | 不动 | 用户买的是结果，还是结果背后的人？ |

成本边界有具体工程实践：让模型输出结构化 JSON 导致调用次数爆炸（半小时视频几十上百次请求），改成纯文本/HTML 输出后调用 33→12 次、单集 31→18 分钟——**"模型输出简单格式，复杂解析交给程序"**，降本公式是调用次数×每次 Token 量×单价。([[baoyu-ai-native-thinking]])

价值边界锚在人性上："AI 自动写小说、做视频，很多人天然抵触，叫'AI 垃圾'；哪怕只让 AI 润色文章，都有读者评论'AI 味很重'"。如果产品只是在生产更多 AI 垃圾，就要想想值不值得做。这条线不随模型升级移动——在两条会动的线上找机会，在那条不动的线内侧建护城河。

## 产品三问（个体版产品过剩）

落成操作规则：现在能做的马上做；半年后能做的**搭架子等模型**，模型进化是你的顺风；很久做不了的用工程补，或者别做。这与 [[product-overhang]] 同构——Boris 提前六个月建 Claude Code 是组织层面的"等模型"，宝玉的"产品三问"是个体层面的操作化。([[baoyu-ai-native-thinking]])
