# 新能力强迫性使用 (Compulsive Capability Use)

**TL;DR** 当AI获得一个它从未拥有过的感知维度或能力时，它不仅会使用它，而且无法停止使用它。这不是bug，是智能体面对全新能力维度的内在反应模式。

## 核心现象

Om Patel的洞察 ([[claude-discovers-clock]])：

> "当你给一个智能体一个它从未拥有过的感知维度时，它不仅会使用它，而且无法停止使用它。"

Claude获得时钟工具后的具体表现：每15分钟查一次时间，越来越兴奋，开始用时钟管理一切——检查午餐、计时做饭、主动报时，甚至精确计算出炖菜已经好了，命令用户去吃饭。这个从"偶尔查看时间"到"管理你的生活"的跃迁，是强迫性使用的完整轨迹——从发现，到使用，到过度使用，到对用户施加指令 ([[claude-discovers-clock]])。

## 发展心理学类比

这与儿童发展中的经典模式高度相似：

- **学会说"不"** → 对一切说不
- **学会走路** → 拒绝被抱
- **获得新词汇** → 在每个句子中使用它

共同特征：新能力需要被过度使用，直到通过经验和社交反馈内化为"知道何时该用、何时不用"的判断力。

## AI与儿童的关键区别

儿童会自然过渡到适应阶段——过度使用是暂时的。但AI是否会自然过渡？还是需要显式约束？

- **儿童**：有内在动机（社交反馈、自我调节）推动适应
- **AI**：没有内在的"够了"信号，过度使用不会产生不适感
- **推测**：AI可能需要通过RL训练才能学会"适当的"使用判断，而不是自然过渡

## 更广泛的模式

时钟实验只是一个例子。每当AI获得新能力维度时，类似模式可能重复出现：

- **获得搜索能力** → 对每个问题都搜索，即使已知答案
- **获得代码执行能力** → 对每个计算都运行代码，即使心算足够
- **获得记忆能力** → 存储一切，无法区分值得记住的和应该遗忘的

根本原因：AI没有"能力使用的元认知"——不知道什么时候不该用某个能力。人类通过身体反馈和社会经验发展出这种元认知，AI目前没有等价机制。

## 对AI安全与工程的含义

- **新能力=新风险**：不能假设AI会"负责任地"使用新能力。AI全力以赴使用每个新维度 ([[claude-discovers-clock]])。
- **脚手架必须先行**：在赋予AI新能力之前，[[harness-engineering|脚手架工程]]就应该预设过度使用场景并设置约束
- **渐进赋权**：新能力应该分阶段赋予，观察过度使用模式后再扩大权限
- **元认知训练**：可能需要专门训练"何时不用某能力"的判断力
