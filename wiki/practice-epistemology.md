# 实践认识论

**TL;DR** 毛泽东《实践论》(1937) 构建了完整的认识论框架：实践→感性认识→理性认识→回到实践检验，螺旋上升。这是wiki"体验不可压缩→智能与智慧"核心链条的哲学底稿——给"为什么体验不可压缩"提供了认识论层面的完整论证：不是因为存在论上不可能，而是认识论上链条断了。

## 核心链条

认识的完整路径：

```
实践（变革现实的行动）
  → 感性认识（感觉、印象、片面、外部联系）
  → 概念、判断、推理（抓住本质、全体、内部联系）
  → 理性认识（理论）
  → 回到实践检验（验证并修正理论）
  → 再认识（循环，每圈升一级）
```

这就是"实践→认识→再实践→再认识"的辩证螺旋。wiki的[[knowledge-compounding|知识复利]]是这个宏观螺旋在微观知识管理上的同构实现：每次ingest≈一次实践→认识的微型循环。

## 两趟飞跃

**第一次飞跃 — 感性到理性：** 没有感性材料，理性是"无源之水、无本之木"。这是[[understanding-as-cloud|理解作为云]]的纵向轴：不从底层感知爬起的抽象层是空的。

**第二次飞跃 — 理性回到实践：** 理论是否正确不知道，只有回到实践中检验才能验证和修正。不回到实践的理论是"空洞的理论"。

两趟都走完，对一个具体过程的认识才算完成。只做第一飞跃不做第二飞跃——是AI的精确位置。

## 四类错误

| 错误类型 | 表现 | wiki映射 |
|---|---|---|
| 经验论 | 停在感知，否认理性飞跃 | [[vibe-coding]]（纯实验不总结） |
| 唯理论 | 脱离感知，空谈理论 | AI的"云挂高层下面空的"([[abstraction-ladder]]) |
| 右倾 | 思想落后于现实推移 | 工程中的"流程僵化" |
| "左"倾 | 思想超越当前实践阶段 | [[product-overhang]]（为下代模型设计产品）|

## 与wiki的连接

- [[experience-incompressible]] — 实践认识论是"体验不可压缩"的哲学根基：感性认识只能从直接实践中来。"模拟"没有实践，就没有感性认识材料，其理性知识是无源之水。体验不可压缩不是在说算力不够（那是[[curse-of-dimensionality]]），而是在说链条断了
- [[intelligence-vs-wisdom]] — 完整走完两趟飞跃=智慧。只从他人文本中提取理论（AI能做的全部）=智能。智慧要求你亲自下水走完全程，因为第二次飞跃"回到实践检验"无法由他人代理
- [[understanding-as-cloud]] — 感知→概念→理论=云的纵向轴。没有底层感性材料的抽象层是虚的。"横向相似度"=理性加工中"举一反三"的能力，"纵向抽象度"=从感性到理论的完整通道
- [[abstraction-ladder]] — 抽象梯每一层都需要实践锚点。能摸到三层以上=云的纵向轴扎实。只挂高层术语=否认第一次飞跃——唯理论错误
- [[fortune-misfortune-dialectic]] — "吃一堑长一智"。选祸→天选福的机制不是宇宙玄学，是认识论：失败强迫你修正对客观规律的认识，修正了就能在实践中胜利。"福"=被实践修正后的正确认识
- [[system-zero]] — "秀才不出门全知天下事"段精准诊断系统0：AI给的答案是无根的理性认识——它有自己的实践链条。'"秀才"能知但不能亲知

## 边界与局限

这个框架不覆盖所有知识。它是关于**实践性知识**的认识论——通过变革现实获得的知识。纯数学、逻辑、形式系统不在它的射程内（这些不依赖感性经验）。但它覆盖了wiki关心的所有领域：工程决策、产品品味、研究能力——这些全部依赖实践经验。
