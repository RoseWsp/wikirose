# 动态规划、贝尔曼方程与维度灾难

## TL;DR

动态规划的名字是贝尔曼为了拿项目经费故弄玄虚的产物，本质是"倒推法"——从终点往回算最优路径。贝尔曼方程浓缩了最优性原理，但撞上了维度灾难：围棋的状态空间 3^361 ≈ 10^172，全宇宙原子才 10^80 个。赫伯特·西蒙的一盆冷水——有限理性——指出完美计算本就不可能，满意比最优更现实。

## 核心线索

1. **最优性原理**：不管前面怎么走，如果你现在在最优路径上，从当前位置到终点的路也是最优的。北京→广州经武汉，若整体最优，则武汉→广州那段也最优。这意味着不需要从起点穷举，从终点倒推即可，复杂度骤降。

2. **贝尔曼方程**：V(S_now) = max[R + γ·V(S_next)]。即时奖励R好算，下一步价值V(S_next)利用前步计算结果——倒推的递归公式。配合价值表（查表法），小规模问题直接可解。

3. **维度灾难**：4个点的车间地图算得了，9格井字棋约5000-6000行，19×19围棋 3^361 ≈ 10^172 行——爆了。这就是贝尔曼撞的墙。明斯基当年担心多层感知机，本质也是怕维度灾难让优化走不下去。

4. **神经网络的介入**：本质上是用函数逼近替代查表——不存完整价值表，用神经网络的泛化能力去逼近它。从动态规划到深度强化学习的桥梁。

5. **西蒙的冷水**：贝尔曼追求完美最优解，西蒙说现实中不可能算完，得"满意就行"（satisficing）。有限理性是对维度灾难的认知层面回应。
