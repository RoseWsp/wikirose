# 李继刚：理解

## TL;DR

理解不是定义，不是分类，是你脑海里那团"云"的形状。云由两条轴撑起：**横向相似度**（广度）和**纵向抽象度**（深度）。

## 核心框架

借用侯世达的"取景框"：理解是脑子里长出一团关于"它"的云。理解不是状态，是形状。

```
抽象度
↑
|
|
+─────────────────→ 相似度
(中心) · · · (近邻) · · · (边缘)
```

**横向相似度**：新事物进来，脑子里"差不多像"的结构被点亮，最亮的被选中，新事物套进该模板完成认知。相似结构越多，云铺得越广——理解的广度。

**纵向抽象度**：同一件事可以贴脸看，也可以站远看。贴脸→站远→站更远→站最远，每一层都能站住，是理解的深度。这就是**[[abstraction-ladder|抽象之梯]]**。

## 关键应用

**费曼："没法向6岁孩子解释就没真懂"**——你必须从高层滑到低层，在低层找到对方已有的"像"来锚定。滑不下去，说明云只在顶层挂着术语，下面是空的。

**费曼："没法重新创造就没真懂"**——rebuild 是在抽象梯上下摸一遍，把云的形状彻底摸清。

**"读了等于没读"**——读的过程中，与主题相关的云的形状没变。信息过了眼，但没改变任何连接的权重。
