# 人选天选论

路飞提出的决策框架：人的选择分"选福"和"选祸"，由贪婪和恐惧两种原始欲望驱动。宇宙定律是人选福时天选祸，人选祸时天选福——所谓"运气"只是这枚硬币的另一面。视频用三个科研场景（读博、选方向、审稿）反复验证同一结构。

## 核心框架

两种动机 × 两种行为 = 四格矩阵：

| | 拿起 | 放下 |
|---|---|---|
| **贪婪** | 选福（贪而取） | 选祸（贪而舍） |
| **恐惧** | 选祸（惧而取） | 选福（惧而舍） |

- **选福**：贪中拿起（追名利读博）、惧中放下（怕难而退）——天选祸
- **选祸**：贪中放下（放弃眼前热门）、惧中拿起（怕不够好而苦练）——天选福

## 三个科研场景

**读博**：为高身份高收入去顶尖学校 = 选福，天选祸（压力大、周期长、毕业不确定）；为在高标准环境锤炼自己 = 选祸，天选福（抗压能力、高水平成果）。

**研究方向**：选热门"流体力学+机器学习"只看表面利益 = 选福；同样选但意识到风险去补基础 = 选祸（惧中拿起）；选"湍流"等难出成果的天坑方向 = 选祸（贪中放下），可能十年磨一剑。

**审稿**：审稿人因恐惧新方向动摇地位而拒稿 = 惧中拿起权力 = 选福（短期赢长期输）；作者沉下心补证明改文章 = 选祸，可能发更高IF期刊。

## 结语

选择无对错，关键在觉察自己的贪婪与恐惧。觉得太苦太委屈时告诉自己"我正在选祸"——上天已在为你准备福报。
